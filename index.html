Guide

Ce que fait l'outil, dans quel ordre, et selon quelles règles.

Mode d'emploi

1. Exporter les données de KoboToolbox

Format XLS, « Valeurs et en-têtes XML », sans inclure les groupes dans les en-têtes.

2. Déposer l'export

Le fichier est lu tel quel, sans retouche. Les colonnes sont reconnues par leur code Kobo.

3. Choisir la visite

Une visite est identifiée par le couple code du chantier et date. Ce sont les deux seules informations à fournir.

4. Vérifier les contrôles

Toute ligne signalée en rouge est une anomalie : valeur manquante, hors champ, NA interdit, numérateur supérieur au dénominateur.

5. Lire le rapport

Alertes, quatre indices, décomposition par paramètre, sous-indicateurs faibles.

6. Archiver la visite

La ligne rejoint l'historique du chantier et devient comparable aux visites suivantes.

Règles générales de cotation

Binaire

1 = l'exigence est entièrement satisfaite ; 0 = elle ne l'est pas. Aucune valeur intermédiaire.

Libellés « Absence de… »

Coter 1 si aucune situation non conforme n'est constatée ; 0 dès qu'un seul cas est constaté.

Maturité

Choisir l'échelon dont la description correspond à ce qui est observé, de 1 à 5.

Taux

Relever le numérateur et le dénominateur, jamais un pourcentage estimé.

Preuve écrite

Pour une formation, une séance, une désignation ou un document, la déclaration orale ne suffit pas.

Non applicable

Uniquement si le critère écrit dans la colonne « NA si » est rempli. Ailleurs, l'absence d'un document vaut zéro, jamais NA.

Emprise observée

Le front de travaux, la base-vie et les installations qui le desservent.

Projets linéaires

Pour un projet couvrant plusieurs voies, l'unité observée est le tronçon en travaux et la base-vie qui le dessert.

Ce que le calcul ne fait pas

Les quatre indices ne sont jamais réunis en une valeur unique. Aucune pondération n'est introduite entre les paramètres ni entre les indicateurs. Les alertes sont signalées à part et n'entrent pas dans le calcul. Les sous-indicateurs non applicables sont retirés du dénominateur sans être comptés comme nuls.
